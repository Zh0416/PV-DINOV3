按来源原图名、影像哈希和相交地理包围框合并场景，再以固定 seed 321 洗牌组 ID；2 组测试、2 组验证、其余 6 组训练。没有随机逐切片拆分。

| 划分 | 空间组 | 图像 | 正样本 | 困难正样本 | 负样本 |
|---|---:|---:|---:|---:|---:|
| 训练 | 6 | 2,791 | 920 | 710 | 1,161 |
| 验证 | 2 | 320 | 158 | 42 | 120 |
| 测试 | 2 | 557 | 222 | 116 | 219 |

训练、验证、测试之间未发现相同 ID、原图、RGB 哈希或地理包围框交叉。该检查依赖 Manifest 提供的来源、坐标系和仿射变换，未独立核对原始地理资料，也没有设置地理缓冲带。测试组为 `0812_Q_0a5aa4566e4f48` 和 `0807_Q_934ae716b5714f`。这些区域在本项目先前实验中已经被查看和使用，所以此划分是**复现开发划分，不是完全未接触的盲测划分**。若要论文级独立外推结论，需另锁定未用于模型与阈值选择的新地理场景或外部数据。

## Episode 采样方案

- 只从实际 Mask 含 255 的图像抽取支持图；1-shot 一张，5-shot 五张。每张支持图必须与 Query 不同空间组，五张支持图不得重复。当前候选数量检查保证每个 Query 组都有至少五张来自其他组的前景图；支持图彼此是否来自不同原图或地理区域，须在 Stage C 采样器中另外约束并核验，不能由候选数量推出。
- Query 允许前景或全背景。训练时在固定空间训练组内选 Query，支持图须与 Query 原图和地理区域分离；验证和测试也只在各自划分内找支持，不跨划分借用训练 Mask。固定 episode 清单和多种子必须在 Stage C/E 落盘。
- 全背景 Query 的 Mask 仍用于训练 CE 和评估 FP；官方 PFENet 的 `SemData` 要求 query 存在待分割类，需要改采样器才能支持本任务，模型 prior/FEM 不因此删除。
- 评估时按全部像素合并 TP/FP/FN/TN，再算前景/背景 IoU、二类平均 FB-IoU、Precision、Recall、F1/Dice；全空 GT 对前景 IoU 的单图定义为无定义，而其 FP 仍进入全局计数。负图另报 FPR、预测 PV 面积占比和连通域数。PV 只有一个前景类，论文跨类别 class mIoU 不适用；可单列 PV 前景 IoU。

Stage B 只完成数据审计和划分，尚未构造训练 episode、运行 PFENet、选择 checkpoint 或评估 Mask。
