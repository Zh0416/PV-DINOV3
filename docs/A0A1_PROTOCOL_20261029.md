# A0 / A1 冻结模型定位诊断

名单来自用户提供的《小样本数据集.xlsx》，60 张（52 张有光伏、8 张无光伏），ID 与人工核对信息记录在 `configs/a0a1_selected_20261029.json`，同时保存源工作簿 SHA256。图像、标签和权重仅在 Kaggle 读取；原工作簿保持不变。

## 数据角色

按已有 manifest 的源影像、图像 hash 和相交足迹合并空间组后隔离：

- 支持组 `0910_Q_f31b2f78ddfe4a`：不含名单影像。按 seed 42/43/44 顺序抽取 3 张不同且互不重叠的正样本；各自形成一次 1-shot 实验，不进行集成。
- 阈值校准组 `0918_Q_4a6bb66935b24c`：从名单以外抽取 4 张正样本、4 张困难正样本和 4 张负样本。校准样本相互不重叠。
- 查询：名单中其余空间组、且 Excel 前景存在情况与标签一致的 58 张（51 张正图、7 张负图）。`pv001191` 与校准组同源，`pv000137` 的 Excel 写无光伏而实际 label 含前景；这 2 张仅输出预览，不计入汇总，不修改原标签。查询组与支持组、校准组完全隔离。

实际运行再次校验输入 RGB / 0或255 掩膜、896² 尺寸、manifest 图像与标签 hash，以及用户填写的前景存在情况。前景存在冲突逐项记录于 `selection_audit.json` 与 `data_observed.json`，只输出预览。空间隔离依赖现有地理元信息；用户筛选的集合仍是开发诊断集。

## A0：GeoRSCLIP 原生图文响应

使用已核验的 `RS5M_ViT-B-32.pt` 完整图像分支和文本分支，QuickGELU，OpenCLIP 默认配套预处理。固定光伏描述与当前 SSPNet 中的 `PV_PROMPT` 相同；不使用 DINO 特征、查询真值或支持标签。

896² 影像按 224² 窗口、112 像素步长提取 49 个窗口。分别计算归一化图像向量与文本向量的余弦相似度，每个窗口分数赋给覆盖像素，重叠处取平均。由此得到全尺寸语义响应。

这是可解释的滑窗定位基线，不是原生稠密分割头。224² 感受范围和滑窗重建限制小目标、边界定位能力。单一光伏 prompt 的响应不等于经过训练校准的光伏概率。

## A1：DINOv3-SAT 前景原型

冻结已核验的 SAT493M ViT-L/16，取零起始第 23 block 的规范化输出；896² 输入产生 `[1,1024,56,56]` 特征。

仅使用支持图标签：将二值前景掩膜按面积下采样到 56²，在支持特征上做加权平均，再进行 L2 归一化，得到一个光伏前景原型。查询 patch 特征归一化后与该原型计算余弦相似度，双线性上采样到 896²。没有背景原型、CNN、可训练投影、DCMA 或解码器。

3 次实验分别使用不同的单张支持图。报告各次指标及均值／标准差；差异代表支持选择敏感性，不代表训练随机性或置信区间。

## 阈值、指标与可视化

不对查询响应逐图 min-max。A0 和每次 A1 使用各自独立的全局阈值：在同一 12 张校准图上，使用 4096 个余弦分数区间，选择前景 micro-IoU 最大的阈值；平局选择更高阈值。查询标签只在响应生成之后用于评价。

因此本轮为冻结模型、少量标签校准的诊断：每次 A1 额外使用 1 张支持掩膜，两者均使用 12 张校准掩膜。不能称为整套实验只用 1 张标注，也不能将阈值校准后的 A0 分割称为完全无标注分割。

报告前景 micro-IoU、F1、Precision、Recall、正图平均 IoU、正图有真阳性的数量及负图误报像素比例。额外给出基于 4096-bin 直方图的近似像素 AP / AUROC，降低单一阈值对判断的影响；不把负图空并集记为 IoU=1。

每张名单影像输出 RGB、真值、A0 响应／掩膜、seed42 的 A1 响应／掩膜。响应色标按校准数据 1%–99% 分位固定，同一方法各图色标一致；它是显示范围，不是分割阈值。另输出支持图与支持标签缩略图、逐图 JSON/CSV、数据角色审计及环境记录。

这些实验比较两个冻结方法的可用性，骨干、空间分辨率和信息来源不同；二者差异不能单独归因于支持集。不会将当前 SSPNet 的已训练基础分割器混入 A0/A1。

## 运行

在 Kaggle 挂载 `zh0416/pv-896` 与 `zh0416/sspnet-dinov3-pv/3` 输出，使用 GPU：

```bash
python scripts/kaggle_a0a1.py
```

输出 `/kaggle/working/a0a1_diagnostic/`，不保存新的训练权重。
