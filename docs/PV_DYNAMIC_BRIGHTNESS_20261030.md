# 保留亮度门控，学习 CAM 融合权重

## 运行前固定的设计

原 `brightness_gate.py` 和 Q75/Q95 参考完全保留。先得到 `S_b=clip(S-P*g,-1,1)`；本次只修改融合系数：`F=(1-alpha)*D+alpha*S_b`。

三个方法：固定 alpha=0.7；可学习全局标量；8→8(3×3/GELU)→1(1×1) 局部门控。后两者用 sigmoid 参数化，均初始化为 0.7。网络只能输出 alpha；没有分割残差、投影层或编码器更新。输入是 D、S_b、z、g、P*g、S_b-D、D 和 S_b 的局部标准差。亮度高不强制对应某一分支。

D、S_b、alpha 分别双线性上采样到 896×896 后再融合。CAM 是余弦分数的凸组合，不是概率。训练内部用固定温度和参考阈值生成 loss logit；它不改变推理 CAM 标度。

复用原 22 张训练图（4 正 18 负）、12 张校准图和 3 张推理支持。训练与支持图不同且空间不重叠；校准、查询的完整空间组禁止进入训练。两个学习方法共享 320 episode，seed=42，每80步按校准 micro-IoU 选择 checkpoint，平局取更早。损失为原生896监督的类别平衡 BCE + 0.5 Dice + 0.01 alpha锚定 + 0.001 TV。具体固定参数见配置。

校准参考亮度和 loss 使用的历史阈值来自原校准集。每个方法每个推理支持独立校准分割阈值；另报告全部沿用原亮度阈值的结果。模型与阈值锁定后才解析 query mask。不按 query 结果追加调参。

当前24张是反复观察的开发子集；三次 support 选择不等于三次训练随机种子或集成。FP 指非光伏背景误报；二值标签不能区分大棚像素。报告必须同时给 IoU、光伏 Recall、FP/FN，以及正图 macro、逐支持结果和 alpha 空间变异。

私有 Kaggle 仅需提取22张训练图的编码器特征；校准和查询分支直接复用原始缓存。权重、密集特征和完整原图不进入公共仓库。

## 结果

私有运行已完成：https://www.kaggle.com/code/zh0416/pv-brightness-dynamic-fusion/1 。全局方法选中80步，局部方法选中160步；均仅按校准集选择。后续240/320步局部方法校准IoU下降，不能用最后一步替换选中模型。

分别使用原12张校准图选择阈值，三次支持各自按像素汇总后取指标均值：

| 方法 | 全24张IoU | 大棚13张IoU | 大棚Recall | 大棚背景FP | 大棚FN |
|---|---:|---:|---:|---:|---:|
| 原亮度，固定0.7 | 49.02% | 47.67% | 85.53% | 789,872.33 | 143,910.67 |
| 学习全局alpha | 49.41% | 47.94% | 85.26% | 773,905.33 | 146,586.67 |
| 局部动态alpha | **51.26%** | **49.80%** | **86.06%** | **726,852.00** | **138,592.67** |

局部相对固定：大棚IoU +2.13个百分点、Recall +0.53个百分点、背景FP -7.98%。局部相对全局IoU +1.85个百分点。三次支持的大棚IoU分别从49.09/46.85/47.06%变为52.67/48.28/48.44%，三次均改善。

全部沿用原亮度阈值时：大棚IoU固定47.67%、全局48.13%、局部49.45%；Recall固定85.53%、全局84.57%、局部86.01%。改善不完全来自阈值重校准。

全局alpha=0.6942895651。局部网络593参数，查询alpha总体范围0.51838～0.79193、平均0.65577；每图56²标准差平均0.03711，确有位置变化。该变化由CAM和亮度等八路输入共同决定，不能解读成已独立证明某一输入的因果贡献。

17张正图按三支持平均IoU，14张提高、3张下降：`pv000125` -4.57个百分点，`pv000017` -1.39，`pv002038` -0.83。其他6张正图的背景FP由36,015.33增加到44,332.67；存在局部代价，不能声称逐图全面改进。

独立复核：432组混淆表、9个校准阈值精确重建；原亮度g、修正语义网格和固定权重查询计数与历史结果一致；所有融合分数位于两路分数之间。权重图在896插值时实现为 `upsample(alpha-.7)+.7`，与双线性插值代数等价，同时消除常数0.7的FP32插值漂移。

报告：`outputs/dynamic_brightness_20261030/index.html`。数值：同目录 `report_metrics.json` 和 `independent_validation.json`；私有运行下载位于 `dynamic_brightness/`，不含模型权重或密集编码器特征。

当前只验证融合先验的小实验，尚未评估对完整SSPNet下游分割的收益。两个学习方法额外使用了22张训练掩膜；固定基线没有这项监督，因此本比较也包含新增监督的收益。后续应保留当前配置，在新的独立空间组验证，随后再接下游分割模块；本轮不依据query改参。
