# 背景误检迭代结果：五个地理空间组交叉验证

本轮已完成 GPU 训练、逐图预测、模型保存和离线复算。按用户确认，现有光伏掩膜正确，掩膜外均为非光伏背景。没有增加大棚类别标注，也没有修改原掩膜。

**默认保留 `residual_balanced` 作为保召回候选：大棚13图背景误检减少57.07%，IoU从49.80%升到66.98%，召回从86.06%升到87.93%。** 另保存 `residual_no_fft` 作为更高IoU的外观特征候选：大棚IoU71.22%，误检减少72.74%，但召回下降0.61个百分点；全24图IoU为73.04%。

## 最终比较口径

- Kaggle 私有运行：[PV Hard Negative Scene Holdout / Version 3](https://www.kaggle.com/code/zh0416/pv-hard-negative-scene-holdout/3)。前两版只按来源场景留出，未合并有地理关联的场景，其结果不作为最终成绩。
- 全量manifest上按同源、重复hash、footprint相交及传递关联合并。24张开发图的8个来源场景合并为 **5个空间组**；每折排除整个组，用其他组训练。
- 原12张校准图独立于这些组，只用于亮度参考和阈值校准；三个支持选择固定。每方案、每折固定seed42与160次更新，不根据该折留出成绩选训练步数。
- 每个支持选择先汇总像素计数计算IoU、Recall等，再取三次均值；FP/FN也是每次支持的均值。三次支持不是三次训练随机种子。
- **此前24张开发查询图现在作为有监督适配开发池使用。** 这些图反复被观察，结果是开发交叉验证，不是全新独立区域测试；新增训练监督也贡献了收益。

## 能得出的结论

1. **可信二值掩膜已经能提供困难背景监督。** 无需先补齐大棚类别，就能训练模型降低非光伏背景响应。同数据重训alpha也降低了误检，说明新增混淆场景监督本身有贡献。
2. **单纯换alpha仍有局限。** 在同一新训练池中，普通残差校正比只重训alpha改善了IoU和召回。新分数为 `F=(1−alpha)D+alpha S_b+r`，有界残差可以改变两个分支响应区间之外的分数。该比较仍包含输出能力和参数量的变化。
3. **目前没有证据支持优先保留这两个FFT描述。** 完整纹理方案与FFT置零方案使用相同17通道结构、初始化、采样与损失；置零后全图IoU提高2.67个百分点，大棚召回提高10.45个百分点。强抑制减少FP的同时，可能大量漏掉真光伏。这只否定本轮简单局部FFT设计，不证明所有频域方法均无效。
4. **困难像素损失有取舍。** 与普通残差方案相比，背景误检进一步降低，但大棚召回下降3.36个百分点。当前辅助项按混合patch的多数类别挖掘，可能伤害很小的光伏；不能把它自动当作最佳训练目标。

## 保留失败样例

两个候选在17张正图上均为15张IoU提高、2张下降，不能声称逐图全面改善。

| 图像 | 原动态alpha IoU | 保召回残差 IoU | 无FFT外观 IoU | 观察 |

| pv002108，大棚小光伏 | 1.87% | 79.30% | 85.34% | 大片背景误检被抑制，保留边缘光伏 |
| pv000915，大棚场景 | 21.31% | 42.33% | 60.56% | 两候选显著降低误检，但外观方案也降低召回 |
| pv002038，大棚场景 | 56.86% | 50.15% | 30.50% | 两候选都退化，外观方案漏检更明显 |
| pv000125，复杂建筑 | 45.93% | 26.96% | 55.58% | 保召回方案在该图仍漏检增加 |
| pv000555，大棚场景 | 73.75% | 77.82% | 53.91% | 外观方案存在明显召回代价 |

纯负7图误检总体下降，但也新增了误检：保召回方案在 `pv001637` 出现约3,413个误检像素；无FFT外观方案在 `pv001791` 出现约16,367个误检像素（均为三支持均值），两图原基线对应误检为0。局部失败仍需要后续针对性数据覆盖。

## 模型保存与实际使用

所有5折×7方案权重及7个全开发池重训候选均已从私有Kaggle下载并核对哈希。**交叉验证表由5个留出模型各预测所属组组成；全24图重训后的单一候选没有独立测试成绩。** 尤其保召回候选在原校准组的IoU均值约35.55%，低于旧alpha约49.33%，说明区域表现仍不均衡；无FFT外观候选约52.19%。不能直接用开发CV表保证全数据重训模型在其他区域的表现。
