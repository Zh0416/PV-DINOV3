# A2：DINOv3-SAT 前景＋背景原型

在冻结 A1 的全部实验设置上，仅增加由同一支持图背景区域提取的单个背景原型。三个支持仍为 `pv001183`、`pv003504`、`pv001177`，各自独立进行一次 1-shot，不集成、不训练。

## 输入、评分与输出

支持 RGB（896²）和二值 label → 冻结 DINOv3-SAT493M ViT-L/16 最后 block23 → `[1,1024,56,56]` 特征。前景 mask 与其补集分别按面积下采样到 56²，分别加权平均特征、L2 归一化，得到一个前景原型和一个背景原型。混合 patch 按前景/背景的实际面积参与两类池化；不增加腐蚀、困难背景挖掘或多原型。

查询 RGB → 同一冻结编码器 → 归一化 patch 特征 `q` → `score=(cos(q,p_fg)-cos(q,p_bg))/2` → 双线性上采样到896² → 单一全局阈值 → 光伏二值 mask。除以2只使响应位于现有直方图的[-1,1]区间，不改变排序或增加超参数。响应不是概率；固定阈值0不是最终采用的校准阈值。

## 数据与阈值

完整沿用 [A0/A1协议](A0A1_PROTOCOL_20261029.md) 的支持、12张校准图、58张查询图及2张仅预览图。支持、校准、查询属于互不相交的完整空间组；`pv000137` 的标注存在冲突，`pv001191` 与校准图同空间组，继续不计入汇总。不修改任何原始标签。

每次 A2 在原12张校准图上，用4096个[-1,1]分箱选择前景micro-IoU最大的阈值；平局选更高阈值。查询标签不选择阈值。每次实验使用1张支持mask＋12张校准mask，与A1的标注数量相同。不得根据本轮查询成绩改变背景构造或评分公式。

## 对照与验收

同次推理重算3次A1作为对照，并与挂载的私有Kaggle A0/A1 Version 2逐图TP/FP/FN/TN及阈值逐项核对。角色名单、空间审计、图像/label hash及前景像素数也必须与上一轮一致；任一不一致即停止标记完成并保留错误。

报告3次配对IoU、Precision、Recall、近似像素AP、负图误报面积/图数；报告小面积、薄云、模糊等分组及支持选择的差异。3次标准差仅代表支持选择敏感性，不是置信区间。AP沿用4096分箱近似值。

输出60张六列对照缩略图（RGB、GT、A1响应/掩膜、A2响应/掩膜，均展示run42）及所有3次支持的逐图指标。热图范围分别由校准集1%–99%分位固定，不逐查询图归一化。模型权重、原始影像和特征不下载到本地、不上传GitHub；只取回文字结果与派生预览。
