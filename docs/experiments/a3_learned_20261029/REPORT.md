## 核验

历史 A2 的全部逐图混淆像素计数完全复现；输出像素总量、支持与数据角色、校准选择及 60 张预览校验通过。视觉投影、文本跨模态映射、语义投影、融合标量与 DCMA 辅助头均有非零梯度和实际参数变化。这证明训练路径接通，效果由上表决定。

局限：仅一个训练空间组、4 张前景训练图、固定训练随机种子；训练步数有界，原文 SGD 改为 AdamW，DINOv3 替换 DINOv2，采用已知光伏类合并方式。当前用户挑选的开发查询已被多轮查看，不作为独立泛化结论。
