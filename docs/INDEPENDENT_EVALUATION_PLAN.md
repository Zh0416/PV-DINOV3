# 下一轮独立评估计划（待人工确认，尚未执行）

本文件只制定计划，不启动训练、评估、阈值搜索或大型模型下载。上一轮 12 张验证图参与过 checkpoint 选择，本轮又进行错误复核，因此不能用作独立测试集。

## 1. 数据独立性与锁定顺序

1. 整理所有已使用、已查看及可能重叠的数据：pilot 训练/验证 ID、此前 Smoke/审计 ID、source_scene、源影像 ID、拍摄时间、CRS、仿射变换、切片窗口以及 uncertainty 来源标记。
2. 优先取得此前未用于训练、调参、模型选择或错误分析的完整原始场景/地理区域。若现有场景已被覆盖，优先新增独立地域；不能把同一场景中“没抽到的切片”自动称为独立测试。
3. 用真实地理 footprint 和统一坐标系识别重叠、接触及邻近区域；将同源影像、重复影像、相交或应被隔离的近邻窗口合并为组。不同文件名、source_scene 或日期并不证明空间独立。投影到合适的米制 CRS 或使用测地距离，核验定位可靠性。
4. 在查看模型测试表现前确定地理缓冲规则。缓冲宽度结合 896 像素窗口实际地面覆盖和空间相关性确定并记录，不能根据测试结果反复修改。缺少地理来源时，暂停“独立”命名并补充元数据。
5. 先按区域分训练/开发验证/独立测试，再按类别取样。验证用于选 epoch、超参数及后续方案，测试只做最后锁定后的比较。保留自然负样本比例；另外报告平衡诊断子集，不混淆两者分布。
6. 三类覆盖以空间隔离优先。某地域缺类别则如实报告，不跨组借样本凑类别。统计真实场景数，不用切片数冒充独立样本数。
7. 由人工在不参考待比较模型预测的条件下核验测试标注规则、空 Mask 和来源不确定性；任何修改均须授权、版本化、记录原值与理由。`source_label_uncertain_filename` 不自动成为忽略标签。本轮 Mask 保持不变。
8. 锁定清单、地理组、标签版本/哈希、数据说明和评估协议。测试集不参与选模型、调阈值、设计提示或筛选误检。当前不生成一个冠以“独立”的新清单。

## 2. 预登记比较方案

| 方案 | 冻结/训练部分 | 保持一致 | 待确认事项 |
| --- | --- | --- | --- |
| A | 冻结 DINOv3-SAT，训练现有根目录 decoder | 固定 SAT revision/SHA、RGB 归一化、896 输入、decoder、损失及划分 | 当前最佳 checkpoint 作为冻结的历史参照；若采用新训练划分，另行授权公平重训 A |
| B | 原 SAT 参数冻结，训练新增 Adapter 和同一 decoder | 与 A 相同划分、预处理、损失、增强、指标和验证选择规则 | Adapter 插入位置/瓶颈维度、初始化、train/eval 行为、可训练参数量和预算需先登记；不预设收益 |
| C（后续可选） | 评估 InternVL 语义提示或伪标签是否增加收益 | 以 A/B 中预先确定的参照为基础；同一锁定测试集 | 仅在明确研究假设和资源授权后考虑，先定义输出如何接入分割及污染检查；不下载或运行 InternVL |

历史 A 使用 48 对训练和 12 对开发验证、3 epoch。直接把新数据、更多 epoch 或更大预算的 B/C 与其比较，不能把差异全部归因于 Adapter/InternVL。后续正式对照需事先匹配训练样本、更新步数/训练预算和验证选择规则，并同时报告参数量、显存、训练与推理耗时。若最终用新训练集，应为 A 安排同条件重训；这需要新的明确授权。

尽可能用多个预登记随机种子（例如 42、43、44）并报告全部结果；先根据资源确认预算，不能挑最好种子展示。新方案选择仅用开发验证，锁定配置后统一运行独立测试。测试结果不反过来挑选 epoch 或阈值。

## 3. 固定的预处理和指标

- Backbone：`vit_large_patch16_dinov3.sat493m`，HF revision `ce148bd5ed3de1eb75ebdccafcb2c280bb3e8f7c`，SHA256 `8d18337f766102f951ac0ca543a22536f58caeb6b6c33cfef73326f866791286`。
- 原始 896×896 RGB，不做测试随机增强；mean `[0.430,0.411,0.296]`，std `[0.213,0.156,0.143]`。保持相同输出插值及对齐规则，Mask 背景 0、光伏 1。
- 所有模型固定 `sigmoid(logits)>=0.5`；本轮及计划中不搜索阈值。若未来研究校准，必须单独用开发集预登记，不能依据测试挑阈值。
- 主要指标：累计 TP/FP/FN 的前景 IoU、F1、Precision、Recall；保存原始计数及每图前景像素数。
- 同时报告逐场景指标及场景宏平均、困难正样本分组、目标占比区间、负样本像素/图像误检率、前景像素漏检率和整图完全漏检数。
- 零分母保存 null；真值及预测均空不人为记 IoU/F1=1。负样本 FP 进入整体统计。平均时列明排除了哪些无定义项，防止空 Mask 夸大成绩。
- uncertainty filename 为元数据分层，报告各组结果和数量，不自动剔除，也不把它当作已确认的标注质量标签。
- 若场景数足够，按地理组进行配对差异分析及组级 bootstrap 区间；不能将相邻切片当作独立样本计算很窄的置信区间。场景太少则明确不稳定性。

## 4. 复现与数据使用边界

每次运行保留 Git commit、数据/标签/清单哈希、SAT revision/SHA、decoder/Adapter 配置、训练种子、随机状态、完整依赖、GPU、AMP/TF32/确定性设置、epoch 日志和最佳 checkpoint 选择证据。独立测试程序应只加载 checkpoint、不创建 optimizer；预测和评估与训练分离。

如果研究 C：记录 InternVL 的精确权重版本、提示词、解码设置、伪标签版本和推理成本；测试标签不得进入提示设计、伪标签筛选或模型选择。不能以反复观察测试预测后设计提示的方式保持“独立测试”名义。对可能的预训练数据重合只能记录证据和未知范围，不宣称绝对无污染。

代码和说明进入 GitHub；原始数据、checkpoint、SAT/InternVL 权重留在 Kaggle。持久化资源保持私有，挂载固定版本，验证真实文件可读及哈希一致后再声明保存完成。
