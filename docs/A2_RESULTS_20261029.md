# A2 光伏实验结果（2026-10-29）

**A2已在Kaggle完成：三次独立1-shot的平均前景IoU由A1的40.52%升至44.05%，提高3.53个百分点；平均Recall由46.92%升至55.42%。但负图误报像素率由0.84%升至2.40%，大棚与复杂建筑组退化。** 当前结果支持继续研究前景与背景的相对响应，同时说明单个背景原型尚不能稳定抑制干扰。

## 这次增加了什么

| 环节 | 实际输入与处理 | 实际输出／作用 |
|---|---|---|
| 冻结编码器 | 896×896 RGB → DINOv3-SAT493M ViT-L/16，第23号block（从0计数） | `[1,1024,56,56]`，提供patch特征 |
| 前景原型 | 一张支持图特征＋光伏label，label按面积下采样后加权池化，再L2归一化 | 一个1024维向量，表示该支持图的光伏特征；与A1相同 |
| 新增背景原型 | 同一支持图特征＋光伏label的补集，以相同方式池化归一化 | 一个1024维向量，表示该支持图背景的平均特征 |
| 查询评分 | 查询图归一化特征分别与两个原型求余弦，计算`(前景相似度−背景相似度)/2` | 56×56相对响应；除以2仅匹配[-1,1]的直方图区间 |
| 分割输出 | 双线性上采样至896×896，再应用该次实验的校准阈值 | 896×896光伏二值mask |

没有梯度更新，没有新增训练权重。背景原型只来自当前支持图，不包含多背景聚类或困难背景挖掘。三张支持图分别运行，既不合并原型，也不集成预测。详细约定见[A2协议](A2_PROTOCOL_20261029.md)。

## 数据与公平对照

沿用A0/A1的全部角色：支持图分别为`pv001183`、`pv003504`、`pv001177`，每次使用相同的12张校准图；58张查询图包含51张正图、7张负图。支持、校准、查询按现有空间信息隔离到互不相交的完整空间组。

每次A1/A2实际使用**1张支持mask＋12张校准mask**。A2在原校准组上单独选择全局阈值：4096分箱、最大化前景micro-IoU、平局取更高阈值；查询标签不参与阈值选择。没有逐查询图归一化或调阈值。

60张名单中的`pv000137`仍存在Excel“无光伏”与label含81,796个前景像素的信息冲突；`pv001191`仍与校准样本同空间组。两张只输出预览，继续不计入指标，原始标签未修改。

同次Kaggle运行重算了三次A1，**60张图×3次A1的TP/FP/FN/TN、校准阈值和所有汇总指标均与上一轮Version 2完全相同**。角色与空间审计、实际读入数据和原文件hash也已核验，保证本轮对照来自同一批数据和设置。

以下指标均为百分数。每次IoU先累加58张图的TP/FP/FN计算，均值再对三个支持选择取算术平均。它不是前景与背景两类的mIoU；AP为4096分箱的近似像素AP。

| pv001183：A2（run42） | 49.08 | 68.96 | 63.00 | 72.66 | 2.4513 | 5/7 |

| **A2：三次均值** | **44.05** | **68.33** | **55.42** | **67.88** | **2.4021** | — |

A2三次配对IoU变化分别为**+2.45、+11.36、−3.21个百分点**。51张正图中，run42有27张提高、23张下降、1张相同；run43为32/14/5；run44为10/39/2。run44虽有少数大目标改善，整体与多数正图仍退化，因此不能只展示最好的run42。

平均F1由57.23%升至61.08%。IoU总体标准差从7.63降至3.57个百分点，仅描述这三个支持选择的离散程度，不能解释为统计显著或已解决支持敏感性。AP在run43提高，而run42和run44下降；这说明平均提升也不等于每次实验的像素排序能力都变好。

负图误报像素率指7张无光伏图中的误报像素占全部像素的比例；只要出现一个误报像素就计入“有任意误报的负图”。该组仅7张，不能据此估计稳定的部署误报率。

校准组也存在值得保留的反向证据：三次A2的校准IoU均低于A1。查询组的改善不能直接外推到其他空间组；本轮保持原协议，没有根据查询成绩重新挑阈值。

## 如何理解，下一步做什么

从公式看，背景原型改变的是查询特征的判别方向，而不是简单在A1掩膜上删除背景。随后重新校准阈值，既可能找回前景，也可能纳入新的干扰。一个支持图的背景平均向量无法覆盖大棚、建筑、田地、水体等多种背景，这是合理的后续研究假设；当前结果尚未分离证明具体原因，不能把全部变化都归因于阈值或某一种背景。

**保留A1与A2两组结果，结论写成“平均IoU和召回改善，但背景误报与场景泛化仍有不足”。** 不应将A2描述为全面优于A1或“成功抑制背景”。本轮协议与评分公式未根据查询结果修改，也没有据此重跑挑选更好的支持。

下一项可以按原设计检验A3语义融合，但要同时保留A1、A2作为对照：先固定融合的输入与公式，只在校准组选择权重和阈值，再报告所有三次支持及同样的失败分组。A0在部分薄云／模糊图上曾有响应，但这只是开展融合实验的依据，不能提前认定融合有效。背景多原型、困难背景挖掘或多层特征可作为之后的单独消融，不与A3同时加入。

本批为人工筛选、已反复查看的开发诊断集。确定方案后，需要新的空间隔离测试组。**本轮完成的是实验表的冻结A2，无模型训练，不代表原论文SSPNet完整训练与基准复现；A3尚未启动。**
