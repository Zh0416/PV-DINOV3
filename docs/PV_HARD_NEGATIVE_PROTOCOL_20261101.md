# 光伏背景误检迭代：空间组留出协议

用户授权自主迭代，并暂按“大棚干扰”场景中的光伏掩膜正确处理；掩膜外为非光伏背景。无需额外大棚类别掩膜，不修改标签。

## 数据角色变化

此前 24 张开发查询图，现在明确成为有监督适配的开发池。每折使用其他空间组训练，当前空间组只用于该折预测；原 12 张校准图仍仅用于亮度参考与阈值校准，三个支持图的掩膜提供固定支持原型。不能沿用“24 张全部未用于训练”的旧叙述。

复用 `pvseg.spatial.scene_groups`：在全量 manifest 上按同源文件名、重复 hash、地理 footprint 相交及传递关联合并整个场景。24 图有 8 个来源场景，但只有 **5 个合并空间组**。校准与支持空间组均不进入开发池；逐折断言测试与训练/校准/支持之间没有 footprint 相交。

V1/V2 仅按 8 个来源场景留出，未合并跨场景地理关联，因此其 72.29% 等结果只属于初步诊断，不能作为最终空间组结果。V3 修正此问题；新结果发布后以 V3 为准。即使 V3，每个预测排除了该空间组，也仍是反复查看的开发池上的交叉验证，不是全新的独立测试。

## 固定比较

| 方案 | 输入 | 损失及用途 |
| --- | --- | --- |
| 历史 fixed / local | 已有 CAM/alpha 缓存 | 两个历史参考，逐图混淆计数必须精确复现 |
| alpha_retrained | 8 路原融合输入 | 同一新训练池重训 alpha，分离新增数据监督收益 |
| residual_balanced | 8 路原融合输入 | 学习 alpha 和有界残差，BCE+Dice |
| residual_hard | 同上 | 增加困难像素辅助损失 |
| residual_spectral | 8 路 + 2 路 FFT | 检查简单频谱描述是否有用 |
| residual_texture | 8 路 + 9 路局部描述 | FFT、RGB/亮度、梯度和纹理；困难像素辅助损失 |
| residual_no_fft | 17 路，但 FFT 两通道置零 | 与 texture 同容量、初始化和采样，检验 FFT 的增量作用 |
| residual_texture_balanced | 全 17 路 | 去掉困难像素辅助项，检验召回损失是否由它引起 |

预处理不使用预测对象的掩膜。FFT 是 RGB 亮度去均值后的 16×16 局部 DFT，提取高频能量占比和峰值能量占比；其余 7 路为 RGB 均值、亮度均值/标准差、平均梯度幅度及平均梯度的平方幅度。各路在图内标准化。这些是常规描述子，不预先声称为原创频域方法，也不把纹理方案全部收益归因于频域。

## 训练和评估

每折每方案固定 seed42，160 次更新，batch8，hidden16，AdamW lr0.002、weight decay0.0001、梯度裁剪10。16×16 掩膜面积比例形成 56×56 软监督；loss logit=20×(score−0.19645)。alpha 从0.7开始，残差从0开始、范围±0.15。保留 alpha 锚定和总变差约束。FP32、TF32关闭。

困难辅助项沿用 V1/V2：按 patch 前景面积是否大于/小于50%分两类，各取损失最高15%，两类均值再平均，权重0.5。主要 BCE+Dice 保留分数标签；辅助项可能误伤混合 patch 中的小光伏，因此必须同时保留无辅助损失对照，不将该项自动认定为改进。

固定更新数，无留出组挑 checkpoint。每模型、每支持选择只在原12张校准图上最大化 micro-IoU，4096分箱；平局取更高阈值。每次支持先汇总TP/FP/FN/TN，再平均三次指标。全24图、大棚13图、纯负7图均用这一口径，FP/FN也报三次支持均值。

保存逐图逐支持计数、每折 checkpoint、alpha/残差网格、训练曲线、原始数据和代码hash。所有开发图重训的候选 checkpoint 只供后续推理与新区域验证，不能把交叉验证成绩写成这一单个模型的测试成绩。

优先选择能降低大棚场景误检且保持召回的候选；同时保存 IoU 更高但召回代价不同的备选。最终归因须结合相同数据的重训 alpha 对照和去 FFT 对照。
