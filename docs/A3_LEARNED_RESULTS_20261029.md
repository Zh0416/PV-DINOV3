# A3 修正实测：先验参与学习，完整分割仍未收敛

此前 `A3_FIXED` 仅融合冻结响应，不能代表 SSPNet 的 DMSF。此次按论文路径训练视觉/文本投影、互补 CAM、融合标量及下游模块，完成基础 160 次、第二阶段 320 次更新。**学习链路已接通，完整网络未通过收敛检查，不能称复现成功。**

运行：[Kaggle PV A3 Learned Prior](https://www.kaggle.com/code/zh0416/pv-a3-learned-prior)，版本 2；训练源码 `a6733794eb2fc2cf43c762ecf62952c5b1e4b15c`。结构与数据协议见 [修正说明](A3_LEARNED_PROTOCOL_20261029.md)，完整表格见 [归档报告](experiments/a3_learned_20261029/REPORT.md)。

## 本次修正了什么

- DINOv3-SAT 查询与支持特征通过共享可训练投影，支持前景原型产生空间 CAM。
- 冻结 GeoRSCLIP 文本向量经可训练三层 MLP 映射至 DINO 空间，再投影至共同隐藏空间，与查询特征构建语义 CAM。
- 两个 CAM 经过残差修正，用 `sigmoid(beta)` 学习全局融合比例。原文也有加权相加，关键是映射与融合均接受训练。
- 融合 CAM 及补图与 CNN 特征、支持原型、层次先验组装，进入 DCMA、ASPP、meta 预测及 base/meta 合并；下游损失反传至先验分支。

## 实测结果

以下为固定 58 张统计查询的前景像素 micro-IoU，分别计算三个保留支持选择后取均值；另有 2 张仅预览。单分支 CAM 为联合训练后的诊断，不是独立训练的消融。

| 输出 | IoU | 精确率 | 召回率 |
|---|---:|---:|---:|
| A2：冻结前景/背景原型 | 44.05% | 68.33% | 55.42% |
| 学习空间 CAM | 41.43% | 68.22% | 51.41% |
| 学习语义 CAM | 37.69% | 80.17% | 41.57% |
| 学习融合先验 | 44.38% | 70.05% | 55.01% |
| 完整网络：校准阈值 | 3.19% | 21.49% | 3.62% |
| 完整网络：固定 0.5 | 0.00% | 未定义 | 0.00% |

融合先验相对 A2 只增加 **0.33 个百分点**，不足以证明稳定有效。完整网络固定 0.5 时全部背景；降低阈值后仍极差，因此问题不只是默认阈值选择。先验图不是最终分割结果，不能用 44.38% 代表完整模型。

| 困难组 | 样本数 | A2 IoU → 融合先验 IoU | A2 背景误检率 → 融合先验背景误检率 |
|---|---:|---:|---:|
| 大棚干扰（有光伏） | 11 | 41.41% → 44.92% | 7.37% → 5.89% |
| 建筑复杂（有光伏） | 4 | 18.97% → 34.07% | 0.68% → 0.40% |
| 薄云干扰 | 3 | 36.46% → 28.53% | 9.09% → 4.41% |
| 影像模糊 | 4 | 31.82% → 26.26% | 5.72% → 3.95% |
| 无光伏负图 | 7 | 无前景类 IoU | 2.40% → 4.38% |

大棚、建筑组的先验有所改善，纯负图误检、薄云与模糊图漏检仍有问题。已核对大棚正图 `pv000095`、复杂建筑 `pv000214`、薄云退化 `pv001155` 和大棚负图 `pv001381` 的对照预览，数值与图像一致。

## 核验与边界

本地与 Kaggle 的 34 项单元测试通过。GPU 完成 320 次成功更新，视觉投影、文本 MLP、文本投影、融合参数和 DCMA 辅助头均有非零梯度与实际参数变化。历史 A2 的所有逐图 TP/FP/FN/TN 完全复现，58 个统计条目、2 个仅预览条目、60 张派生预览及聚合计数校验通过。核验状态 `passed` 表示产物完整与计数一致，**不表示模型效果通过**。

校准规则选第 80 步，空间权重为 0.668090，初值为约 0.668188；所选时刻的权重变化很小。第 80/160/240/320 步校准先验 IoU 为 23.62/21.44/20.93/19.98%，训练损失下降没有带来持续的校准改善。

相对无训练 A2，本次增加 22 张训练 mask（仅 4 张含前景）与一个训练空间组，另用 12 张校准图选阈值。它是有额外监督的已知光伏类开发实验；不属于纯融合消融、全程仅一张标注、独立泛化测试或原文新类 benchmark。原文训练优化器与日程也未逐项等同。

首次提交在阶段切换检查处发现基础训练遗留 `.grad`，第二阶段更新数为 0；已在冻结边界清理梯度并增加回归测试，版本 2 重新完成。训练与选择配置未因查询结果修改。此次下载的原始 `summary.json` 把全背景的未定义精确率写作 0，报告生成器从逐图计数重算为“未定义”，后续训练脚本也已修正该汇总表示；像素计数和 IoU 不受影响。
