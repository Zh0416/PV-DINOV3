## 检查与解释

320/320 次更新损失有限，必要学习路径有非零梯度和参数变化，Kaggle 39 项测试通过。所有 60 图×3 支持选择的 A2 混淆计数与历史完全一致；离线重算了检查点选择、每图计数、整体和分组汇总。

meta 与 final 几乎相同，性能差距在 meta 阶段已存在，不能只归因于最终 base 合并。融合先验与完整输出之间仍有明显落差，后续应优先检查先验在下游的使用、训练场景覆盖和 base 跨场景适配；当前证据不能确定唯一根因。

这仍是 SSPNet 方法重建和已知单类别光伏有监督适配。训练仅一个空间组，查询集此前已多次查看，没有独立空间测试集，不能宣称原文 base/novel few-shot 指标复现或独立泛化成功。
