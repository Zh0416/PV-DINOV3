# A3：A2与GeoRSCLIP语义的空间对齐与固定融合

本轮按用户实验表的A3执行：冻结A2＋GeoRSCLIP语义响应。用户重点关注大棚和复杂建筑误检，同时检查光伏漏检。协议在新查询结果产生前固定；不加入A4动态热图校准、解码器或训练式跨模态投影。

## 特征如何对齐和融合

- DINOv3-SAT493M保持A2：896²输入→1024×56×56，归一化patch特征`d`与同一支持图前景／背景原型`p_fg,p_bg`得到`s_D=d·(p_fg-p_bg)/2`。
- GeoRSCLIP保持A0的完整ViT-B/32图文分支、QuickGELU、预处理和固定光伏prompt。896²输入用224²窗口、112步长，得到49个已L2归一化的512维图像向量；文本向量`t`也L2归一化。
- 将每个窗口向量赋给其覆盖的DINO网格：每窗14×14格、步长7格，重叠取平均，得到512×56×56特征`c`。896像素原点与网格严格对应。**平均后不再次归一化**，使`c·t`保持重叠窗口余弦的均值。
- 1024与512通道保持各自坐标，不直接逐通道相加。可写成1536维分块向量`z=[sqrt(1-a)d,sqrt(a)c]`及前景锚点`u_fg=[sqrt(1-a)p_fg,sqrt(a)t]`、背景锚点`u_bg=[sqrt(1-a)p_bg,-sqrt(a)t]`，输出`z·(u_fg-u_bg)/2=(1-a)s_D+a(c·t)`。负文本只是线性评分的代数写法，不是新训练的背景文本或独立背景语义原型。
- 实现按上式等价地融合两个标量响应，避免物化1536通道张量；空间对齐发生在GeoRSCLIP特征网格构造中。双线性上采样与线性融合可交换，统一使用`align_corners=False`，得到896²分数和二值mask。

这是**空间对齐、固定线性特征读出（等价于响应融合）**，没有学到将DINO和CLIP旋转到同一语义坐标系的映射。CLIP窗口的原始感受范围仍为224²，插值不会创造精细边界。整条拼接向量不再次L2归一化。

## 校准与不变的对照

完整沿用A0/A1/A2的数据角色：三个独立1-shot支持、原12张校准图、58张查询（51正7负）和2张仅预览，空间分组及标注冲突隔离规则不变。每次1张支持mask＋12张校准mask，无梯度更新、无集成。

固定候选语义权重`a=0,0.1,…,1.0`。每个候选在原12张校准图上为三个支持分别选4096分箱的最大micro-IoU阈值，再按三次校准IoU的均值选**一个共享全局权重**；平局优先更小语义权重，阈值平局仍取更高值。权重与阈值同用12张校准图，因此校准IoU不是无偏验证结果。查询标签不传入权重选择函数。

保留完整候选校准曲线。`a=0`允许退回A2；若被选中，应如实报告本协议未证明加入语义有增益。查询结果产生后不调整网格、prompt、融合公式或候选权重。

同次运行必须重算原A0、三次A1和A2，逐图TP/FP/FN/TN、阈值及汇总指标与挂载的前次完成版本完全相同，否则停止完成标记。额外输出仅空间对齐的Geo语义分支`GeoAligned`，以区分原A0与网格平滑的影响。

## 输出与边界

报告全部三次A3及均值，与A1/A2配对比较IoU、Precision、Recall、近似像素AP、负图误报像素率／图数，重点列出大棚、复杂建筑、小面积、模糊与薄云组。支持差异标准差不是置信区间；本批仍为反复使用的开发诊断集。

输出60张八列run42预览：RGB、真值、原A0响应、A1掩膜、A2响应／掩膜、A3响应／掩膜。固定校准色标，全部三次逐图指标另存。原始影像、权重和特征仅在Kaggle；本地仅取回报告和派生缩略图。
